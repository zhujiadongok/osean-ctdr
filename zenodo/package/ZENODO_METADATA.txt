Title:
OSEAN-CTDR supporting data: Vaccine Ontology, CTDR feature sidecars, and frozen evaluation artifacts

Creators (match manuscript):
Zhu, Jiadong; Yeh, Feng-Yu; Zheng, Jie; He, Yongqun

Description:
Supporting data for OSEAN-CTDR (SEA-CDM–based vaccine trial evidence integration and ontology-guided design-field prediction). Includes the Vaccine Ontology OWL file used in analyses (release 2026-06-12), CTDR feature sidecars, frozen result JSON artifacts, and class-label helpers. Companion code: https://github.com/zhujiadongok/osean-ctdr. Full AACT dump is not redistributed; local snapshot identifiers and checksums are documented in README.md and the manuscript Table S8.
