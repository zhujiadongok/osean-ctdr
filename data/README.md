# Data sidecars

`sea_cdm_v14/` holds the **CTDR feature tables** used in the paper analyses (not the full official SEA-CDM core dump).

| File | Role |
|------|------|
| `study_context_profile.csv` | disease/phase/purpose/enrollment/design labels |
| `study_intervention_profile.csv` | route / dose |
| `../osean_kg/subject_demographics_summary.csv` | sex / age flags |

Full AACT pipe dump and complete SEA-CDM core tables remain local / for Zenodo if needed; checksums are listed in the manuscript Table S8.
